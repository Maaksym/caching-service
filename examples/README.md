# Приклад вхідних даних

input.json містить два списки рядків однакової кількості елементів.
JSON не підтримує коментарів, тому пояснення розміщено в цьому файлі.

Команда cache-cli --input examples/input.json --repeat 3 працює так:

1. cli.py: main() читає параметри.
2. cli.py: read_input() читає вміст input.json і перевіряє його.
3. cli.py: run() тричі надсилає POST, отримує ID, надсилає GET і друкує результат.

Сервер отримує JSON-вміст; йому не потрібен доступ до локального файлу.
list_1 і list_2 — вхід, а output — кінцевий рядок відповіді GET.
Порядок: перший елемент першого списку, перший другого, другий першого, другий другого.

--output results.jsonl зберігає відповіді CLI по одному JSON на рядок.
У JSON Lines теж немає коментарів. Це клієнтський звіт;
серверні результати лежать окремо в data/payloads/{id}.json.

Вхідний файл і stdin мають бути UTF-8. read_stdin_utf8() читає байти,
write_utf8() записує UTF-8 відповідь незалежно від Windows cp1251/cp1252.
Для збереження UTF-8 файлу використовуй --output, бо оболонка може перекодувати >.
